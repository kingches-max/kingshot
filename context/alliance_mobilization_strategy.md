### 1.2 일일 운영 순서 & 핵심 철칙
1. **티켓 적립 (`09:00`) & 가성비 과금**: 상단 `[+]` **`무료 1 + 50💎 × 3회` 칼스톱** (`4장/일` = 전용 `4/4`와 1:1 완충) + 회차당 **`전력 동원 패키지 (₩3,000)` 1회 구매** (`임무 선택권 4장` 확보 ➔ 차주 이월분 합산 `5일+` 연속 `200% 주먹`).
2. **낮 전용 `우측 2/2` (`120%` 2회)**: `5분` 무료 리롤로 **`🐻 곰 (+360)` · `🦁 사자 (+360)`** 2회 완주 (`좌측 200%` 슬롯은 `23:00`까지 보존).
3. **공용 보드 잉여 티켓 (`기본 9장` 이월분)**:
   * **당일 남은 전용 몫 (`좌측 2장`)만 바닥선으로 보존**하고, 잉여분은 날짜·횟수 무관 **`🟡 주황 곰·사자 (+300)`** 뜨는 대로 즉시 선점 *(🟣 보라 `+180~220`은 토요일 마감 임박 시에만 차선 / 🔵 파랑 `+120~160` 절대 금지)*.
4. **`🦁 사자` 타임캡 룰**: 평시 낮(`~19:00`) **최대 `2시간` 컷** (`선 절반 직접 집결 ➔ 무료 합류 대기 ➔ 90분 체크 후 잔여분 직접 마감`) / **`21:50` 이후 신규 수락 금지** (`23:00` 주먹 슬롯 보호).
5. **`15:00` ~ 당일 밤 `23:51` 좌측 `2/2` 완주 루틴 (아침 타임어택 제거 & `120%` 조건 완화)**:
   * **`07:40`**: 오전 3병영 풀세트 착공 (`7h 51m` ➔ **`15:31` 완료**).
   * **`15:00`**: 좌측 `200%` 슬롯에 **`임무 선택권` ➔ `200% 주먹 (+860)` 미리 수락** *(오터치 사고 `0%`)*.
   * **`15:31`**: 3병영 1차 수령(`~60K`) + 즉시 3병영 풀세트 재착공 (`7h 51m` ➔ **당일 밤 `23:24~23:51` 완료**).
   * **당일 밤 `23:24~23:51`**: 2차 수령(`120K+`) ➔ **`[완료 수령]`** ➔ **`2분` 뒤 좌측 마지막 `120%`가 당일 밤에 바로 오픈**되어 밤+익일 아침(`~08:50`) 내내 여유 리롤 가능!
   * **`120%` 마감 완화 기준**: `🐻 곰(4부대 7분 컷)` · `🦁 사자` 외에 리롤 지연 시 **`전 등급 주먹(+520/+260/+160)` · `훈련/건설 가속`**을 보유 전용 가속 여유분으로 `10초` 컷 허용하여 슬롯 증발 원천 차단.

### 2.2 핵심 시스템 규칙 요약
* **티켓 일일 가격**: `1회 무료` ➔ `2~4회 50💎` ➔ `5~7회 200💎` ➔ `8~10회 1,000💎` (미사용분 이월).
* **전용 한도 & 쿨타임**: 일 최대 **`4개` — 슬롯별 `2회` 제한 (`좌측 2회: 200% ➔ 120%` / `우측 2회: 120% ➔ 120%`, `완료 시점` 기준 차감)** / 완료 후 **`2분`**, 수동 무료 리롤 **`5분`** *(`500💎` 스킵 금지 / 각 슬롯 `2회` 소진 시 익일 `09:00`까지 대기 전환)*.
* **버튼 구분**: 우상단 청록 `[🔄]` = `임무 선택권` / 카드 본체 터치 ➔ 주황 `[임무 새로고침]` = 무료 `5분` 리롤 (`200%` 일반 리롤 시 당일 `120%` 전환, **단 `수락 후 포기` 시 미완료 판정으로 `200%` 재등장**).
* **판정 구분**: `[>>]` 가속 = 클릭 즉시 분수 반영 / `[▲]` 전투력 = 완공·병사 수령 시점 반영.
