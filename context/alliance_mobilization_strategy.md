# 🏆 연맹 총동원 (Alliance Mobilization) 실전 전략

> **핵심 요약**: **`33장 실리 체제` (`기본 9 + 매일 무료 1 + 매일 50💎×3 = 총 900💎`, 평시 `200💎` 매수 금지)** · **전용 `4/4` 질적 극대화로 무위험 `이정표 Lv.21 + 11~20위` 확정 (`전설 조각 총 7개` + 순현금 흑자)** · **`Top 10`은 토요일 마감 직전 `200💎 1~3장` 확정 역전 각일 때만 스나이핑**

## 1. 미션 수락 우선순위 및 일일 실행 원칙

### 1.1 미션 수락 티어표 (`전용 120% · 200%` 기준)
| 판정 | 임무 종류 | `120%` | `200%` | 운용 기준 |
| :---: | :--- | :---: | :---: | :--- |
| **👑 1순위** | **`[주먹 + ▲]` 병사 훈련/승급 전투력 `+120,000`** | **`+520점`** | **`+860점`** | **즉시 클리어 1티어** (`임무 선택권` 고정 타겟 / 공용 주황 **`+430점`**) |
| **🔥 2순위** | **`[곰 얼굴]` 야수 처치 (`30마리`) / 괴수 집결 처치** | **`+300~360`** | **`+400~600`** | **수~금 주력 엔진** (`황야의 시련` + `다이애나` 자동 사냥 판당 `270 스태미나` 무가속 소화) |
| **⚠️ 조건부** | **`[책/망치 + >>]` 연구·건설·통합 가속 `3,600분`** | `+360점` | `+600점` | **중복 이벤트일 즉시 완주 시에만** 수락 (`화 09:00` `기술 발전` 연구 / `금 09:00` `전투력 향상` 건설) |
| **❌ 리롤** | **`[빨간 깃발]` 대형 채집(`3,000만`) / 훈련 가속 `3,600분` / 소형(`≤250점`)** | `+160~360` | `+480~600` | 대형 채집은 `12~20h` 슬롯 락·익일 쿼터 침범 / 훈련 가속은 `[주먹+▲]`이 2배 고효율 ➔ 무료 리롤 |
| **🚫 금지** | **패키지 구매 / 다이아 / 조각 / 망치 / 영주장비** | 패스 | 선택권/리롤 | 과금 유도 및 `최강 영주`·`룰렛` 봉인 재화 ➔ 즉시 교체 또는 무료 리롤 |

### 1.2 일일 운영 순서 & 슬롯 락 방지 철칙
1. **티켓 적립 (`09:00`)**: 상단 `[+]` ➔ **`무료 1회 + 50💎 × 3회` 칼스톱** *(`200💎` 화~금 선제 매수 금지 — 매몰비용 리스크 차단)*.
2. **`200%` 전용 (일 `1회`) 처리 기준**:
   * **선택권 보유일 (`화·수`)**: 자연 `병사 훈련(+860)` 등장 시 그대로 수락, 외 전 종목은 **`임무 선택권 1장` ➔ `병사 훈련(+860점)` 교체 확정(슬롯 아이콘 변경 확인) 후 `[수락]`** 1분 컷.
   * **선택권 소진 후 (`목~토`)**: `병사 훈련` · `야수` · `괴수` · `(금요일 한정) 건설/통합 가속(+600)`만 수락하고, 외 종목은 무료 리롤로 지워 `120%` 실속 미션 전환.
3. **`120%` 전용 (일 `3회`) `4/4` 전량 회수**: 좌·우 2칸 동시 **`5분` 무료 새로고침**으로 전용 칸이 닫힐 때까지 매일 `4/4` 소화.
4. **공용 보드 (`100%`) 선점 스나이핑 & 컷오프** *(공용 보드는 `09:00` 일괄 리셋 없이 수락·`R4/R5` 삭제 시마다 개별 `30분` 쿨 갱신)*:
   * **선(先) 공용 스나이핑**: 전용 슬롯은 남이 못 뺏어가므로, 전용 `4/4` 진행 전이라도 보드에 **`주황 야수·괴수(+300)`** 가 떠 있으면 **즉시 먼저 낚아채고**, 진행되는 동안 전용 2칸 `5분` 무료 리롤을 돌려 다음 전용 타겟을 미리 세팅.
   * **`화 ~ 금요일`**: **보라색 전면 금지 — 오직 `주황색 (+300~450점)`만 수락** (`야수·괴수 +300` / `병사 훈련 +430` / 금요일 한정 `건설·통합 가속 +450`).
   * **`토요일` (전용 `4/4` 마감 후)**: 잔여 티켓이 **`4장 이상`** 남았을 때만 소멸 방지용 보라 `괴수·야수(+200~220)` 허용 (`3장 이하`면 끝까지 주황색만).
5. **슬롯 락 차단**: 즉시 `100%` 완료 불가 미션 선(先) 수락 금지 (`괴수`는 오프라인 직전 익일 `09:00` 전 완주 물량만 수락).

## 2. 보상 가치 vs 투자 손익분기(ROI) 감사 & 규칙 레퍼런스

### 2.1 구간별 보상 가치 및 다이아 투자 타당성 (`초급` 리그, 이정표 `Lv.21` 별도 `전설 조각 5 + 망치 5 + 1,800+💎` 공통 수령)
| 목표 구간 | 랭킹 보상 (`11~20위` 대비 차익) | 필요 티켓 · 투자 | 냉정한 손익(ROI) 판정 |
| :---: | :--- | :--- | :--- |
| **`11~20위` (실리 본선)** ⭐ | `전설 조각 2` + `1,000💎` + `6h` | **`33장` (`900💎`)** | **👑 압도적 최선 (무위험 대흑자)**: `900💎` 지출로 현금 `1,000💎` 즉시 환급(`+100💎` 순증) + `전설 조각 2개`(이정표 합산 **`총 7개`**) 공짜 확보 |
| **`4~10위` (토요 스나이핑)** | `전설 조각 4` + `1,500💎` + `9h`<br>*(차익: `+500💎 + 조각 2개[1,750~3,000💎] + 3h`)* | 토요일 마감 직전<br>**`200💎 × 1~3장` (`+200~600💎`)** | **⭕ 조건부 흑자**: 마감 직전 `1~3장`(`+400~1,300점`) 차이로 **역전이 100% 확정일 때만** 매수 (`실부담 ≤100💎`로 조각 2개 추가) |
| **`4~10위` (화~금 선매수 추격)** | 상동 *(실패 시 차익 `0`)* | 화~금 선제 매수<br>`200💎 × 8~15장` (`+1,600~3,000💎`) | **❌ 비추천 (고위험 저마진 함정)**: `[SHD]` 과금러들의 `패키지 미션(+1,050~2,100점)` 변수로 `11위` 밀릴 시 **`1,600~3,000💎` 전액 매몰 증발**; 성공해도 조각 구매 단가(`550~1,250💎/개`)가 `룰렛(875💎)` 대비 실익 미미 |

### 2.2 핵심 시스템 규칙 요약
* **티켓 일일 가격**: `1회 무료` ➔ `2~4회 50💎` ➔ `5~7회 200💎` ➔ `8~10회 1,000💎` (미사용분 이월).
* **전용 한도 & 쿨타임**: 일 최대 **`4개` (`200% 1 + 120% 3`, `완료 시점` 기준 차감 — 전날 수락분도 익일 완료 시 익일 한도 차감)** / 완료 후 **`2분`**, 수동 무료 리롤 **`5분`** *(`500💎` 스킵 금지 / 한도 소진 슬롯은 익일 `09:00`까지 `~23h` 대기 전환)*.
* **버튼 구분**: 우상단 청록 `[🔄]` = `임무 선택권` / 카드 본체 터치 ➔ 주황 `[임무 새로고침]` = 무료 `5분` 리롤 (`200%` 일반 리롤 시 당일 `120%` 전환, **단 `수락 후 포기` 시 미완료 판정으로 `200%` 재등장**).
* **판정 구분**: `[>>]` 가속 = 클릭 즉시 분수 반영 / `[▲]` 전투력 = 완공·병사 수령 시점 반영.
