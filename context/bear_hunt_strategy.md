## 2. 30분 실전 운영 방법 (Step-by-Step)

### ① 시작 직후 & 5분마다 반복: [내 집결(A) 오픈 — 2군 투입]
1. 이벤트가 시작되면 곰 함정을 눌러 **[집결(5분)]** 을 엽니다.
2. 영웅은 **`헬가 + 제이벨 + 퀸`** 을 넣고, 병사는 **1군(정예 궁/기병)을 뺀 나머지 `2군 병력(44K~55K)`** 만 태워서 집결을 열어둡니다.
3. 내 집결에 누가 어떤 영웅을 들고 타든 **신경 쓰거나 강퇴하지 말고 그대로 놔둡니다.** (5분 뒤 자동 출발 ➔ 복귀하면 다시 바로 오픈하여 30분간 **총 5회** 타격)

### ② 30분 내내 상시 반복: [1군 초정예 부대(B)로 '500K 고래 집결' 저격]
1. 연맹 전쟁(집결 목록) 창을 열어두고, **연맹 랭킹 1위·2위(집결 용량 `500K`짜리 고과금러)** 가 연 집결을 찾습니다.
2. 해당 집결에 들어가 저장해 둔 **[1군 프리셋(`첸코` + 정예 궁/기병)]** 을 눌러 즉시 탑승합니다.
   - **체크 포인트 1 (이동 시간 제한)**: `남은 집결 대기 시간`이 내 도시에서 그 집결지까지 걸어가는 `이동 시간`보다 길어야 참여가 가능합니다.
   - **체크 포인트 2 (자투리 좌석 회피)**: 만약 그 집결의 남은 병력 한도가 내 부대보다 턱없이 적은 자투리(`20K~30K` 이하)만 남았다면 내 1군 병력이 강제로 깎여서 들어가므로 타지 말고, 그다음 상위 랭커(3~5위)의 출발 임박 집결에 탑승합니다.
3. 1군 부대가 곰을 때리고 내 도시로 복귀하는 즉시, 다시 **가장 빨리 출발하는 최상위 랭커(1~5위)의 집결**에 똑같이 반복 탑승합니다. (30분간 **약 8~12회** 타격)

## 5. 연맹 공지 / 채팅창 공유용 텍스트 템플릿

### [버전 1] 연맹 우편 / 전체 공지용
```text
[곰사냥 딜 2배 올리는 필수 규칙 3가지]

곰은 반격을 안 해서 '공격력/파괴력'만 중요합니다.
다 같이 보상 많이 받기 위해 딱 3가지만 꼭 지켜주세요!

1. [가장 중요] 남의 집결에 탑승할 때 '1번 영웅(맨 왼쪽)'
- 맨 왼쪽 자리에는 무조건 [첸코 / 연우 / 아마네] 셋 중 하나만 넣어주세요!
- 이 영웅이 없으면 1번 자리는 비워두거나, 영웅 없이 병사만 보내주세요.
- (주의) 하워드, 다이애나, 고든 등을 맨 왼쪽에 넣으면 연맹 전체 공격 버프 자리(4칸)를 막아버려서 집결 전체 딜이 크게 떨어집니다.

2. [병사 편성] 보병은 줄이고, 궁병/기병 몰빵!
- 곰사냥에서는 7등급 보병보다 3~4등급 궁병/기병이 딜이 더 셉니다.
- 보병은 높은 등급으로 소량(약 5천 명~10%)만 넣으시고,
- 나머지는 보유하신 [궁병 + 기병]을 높은 등급부터 꽉 채워주세요! (1~5등급 저등급 보병은 절대 빼주세요)
- 약한 부대 여러 개 보내기보다, 궁병/기병을 꽉 채운 '정예 1~2부대'로 빨리 복귀해서 여러 번 타는 게 점수가 훨씬 잘 나옵니다!

3. [집결 여는 분] 함정 앞 상위 랭커만 오픈!
- 곰 함정 바로 옆에 계신 상위 전투력 분들만 시차를 두고 집결을 열어주세요.

※ 출발 전에 [부대 편성 저장] 해두시면 곰사냥 때 터치 한 번으로 편하게 보내실 수 있습니다!
```
