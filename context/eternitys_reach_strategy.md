# 🏛️ 사라진 유적 (Eternity's Reach) 실전 전략

> **핵심 목적**: `영주 보석` 재료(`보석 도면` · `보석 매뉴얼`) 파밍 (격주 화요일, 30분 개인 전장, 병력 실제 손실 `0명`)

---

## 1. 전장 내 스킬 트리 & 30분 실행 순서 (실전 컨닝페이퍼)

### 1.1 고정 스킬 트리: **`오 ➔ 오 ➔ 왼 ➔ 왼 ➔ 오`**
1. **Lv.1 `우`**: `체사레 수비병` 처치 시 **`+1,500점`** *(쿨타임 없음, 35마리+ 목표)*
2. **Lv.2 `우`**: 수비병 공격 행군 속도 **`+25%`**
3. **Lv.3 `좌`**: 일반 광맥 점령 시 **`+5,000점`** *(전 부대 공통 쿨타임 60초 — 억지 핑퐁 금지)*
4. **Lv.4 `좌`**: 광맥 채집 속도 **`+15%`**
5. **Lv.5 `우`**: **[액티브]** 60초간 채집 속도 **`+50%`** *(`불안정한 광맥` 진입 시 수동 발동)*

### 1.2 시간대별 행동 순서
1. **`00:00 ~ 00:03` (자리 선정)**: 수비병은 무시하고 **`Lv.2~3 광맥` 3~4개 밀집지 한가운데**로 성 무료 이동 *(광맥은 고정, 수비병은 무한 리젠)*
2. **`00:03 ~ 스킬 4렙 달성`**: `1~4번` 전 부대로 내 주변 **`체사레 수비병`만 연속 사냥**
3. **`스킬 4렙 ~ 종료` (평시 운영)**:
   * **`1·2·3번 부대`**: 주변 **`Lv.2~3 광맥` 끝까지 풀 채집** *(고갈 후 이동 시 자연스럽게 `+5,000점` 발동)*
   * **`4번 부대`**: ① 광맥 옆 반짝이는 **`청동석 더미(주머니)` 즉시 회수** + ② **`체사레 수비병` 무한 사냥** 반복
4. **`10분경` & `20분경` (`불안정한 광맥` 분출 — 총 2회)**:
   * 알림 즉시 `1~4번` 전원 귀환 ➔ 주변 **`불안정한 광맥`(개당 `+4,000점` 초고속 채굴)** 에 4부대 연속 투입 + **`Lv.5 액티브(+50%)`** 터치 ➔ 종료 후 바닥 `청동석 더미` 회수 후 3번 복귀
   * *(`30:00` 종료 시 귀환시키지 않고 채집 유지 상태 그대로 자동 정산)*

## 2. 입장 전 체크리스트 & 프리셋 4등분 편성

### 2.1 입장 10분 전 필수 조건
* [ ] 최소 15분 전 타임슬롯 예약 완료
* [ ] 모든 행군 대열 성내 귀환 & **연맹 `자동 참여 OFF`** *(종료 후 `ON` 복구)*
* [ ] 야전병원 부상병 **`0명`** 치료 완료 *(패배 시 병사 손실 없이 해당 부대 5분 출정 쿨타임만 발생)*
* [ ] 프리셋 저장 후 종료 시까지 병영 신규 승급 일시 보류
