## 3. 보상 구조 · 영주 장비 기준 · 완료 로그 (참고)

### 3.1 랭킹 보상표 (`2회차` 전 단계 실측 확정)
* **일일 단계 랭킹**: `51~100위` = `1,200 다이아` + 가속 + **(`2·3단계` 한정) `황금 열쇠 1개`** (`21~50위` = `2,000 다이아`)
* **총 랭킹**: `51~100위` = **`4,800 다이아` + 가속 `27h`(`각 9h`)** / `21~50위` = `8,000 다이아` + `36h` *(전설 조각은 `1~10위`에만 존재)*

### 3.2 `영주 장비` 부위 순서 및 초반 재료표 (`3부위 방어 / 6부위 공격 세트 효과`)
* **강화 순서**: ① **보병 (`코트 · 바지`)** ➔ ② **궁병 (`벨트 · 무기`)** ➔ ③ 기병 (`모자 · 시계`)
* **`비단` 수급량**: 직접 오픈 `Lv.4 = 20개` (`Lv.3 = 15개`, `다이애나` 편성 `20 스태미나`) / **연맹 합류(일 50회 무료 보장, `스케어 울프 50회`와 별도 카운트 분리!)**: `Lv.4 = 4개 (80%, 40회 = 160개)` + `Lv.3 = 2개 (20%, 10회 = 20개)` = **보수적 기준 일일 `180 비단/일` 고정 유입**
* **등급별 비용**: **초록 0성** = 부위당 `비단 1,500 + 금사 15` (`6셋: 9,000 / 90`) · **초록 1성** = 부위당 `비단 3,800 + 금사 40` (`6셋: 22,800 / 240`) · **파랑 0성** = 부위당 `비단 7,000 + 금사 70` (`6셋: 42,000 / 420`, `초록0➔파랑0 6셋 누적: 64,800 / 660`) · **파랑 1성** = 부위당 `비단 9,700 + 금사 95` (`6셋: 58,200 / 570`, **`초록0➔파랑1 6셋 누적: 123,000 / 1,230`**) · **`파랑 2성(45) ➔ 파랑 3성(50) ➔ 보라 0성(60) ➔ 보라 1성(70)` 구간은 `비단 0 · 금사 0`으로 오직 `설계 스케치`만 소모!** *(이후 `보라 2성`부터 다시 `비단 6,500 + 금사 65 + 스케치 40` 소모)*
