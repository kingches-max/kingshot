# 🎯 전 이벤트·콘텐츠 병과 비율 (`보 : 기 : 궁`) 마스터 표

> **공통 원칙**: 내 병력이 나가는 전투는 상세 탭에서 **`1~6등급 = 0명`** 확인 필수!

---

## 1. 일반 전투 · 이벤트 · 전장 (내 보유 병력 출정)

| 구분 | 이벤트 / 콘텐츠 | 영웅 편성 | **보 : 기 : 궁 (%)** | 핵심 포인트 |
| :---: | :--- | :--- | :---: | :--- |
| **보스극딜** | **자이언트 베어 사냥 (곰사냥)** | • `A`: 헬가·제이벨·퀸<br>• `B`: 첸코·하워드·다이애나 | **`0 : 50 : 50`** | 보병 딱 **1명**만 배치 (`A·B` 반반 분배) |
| **대표부대** | **연맹 챔피언십** | 헬가 · 제이벨 · 퀸 | **`50 : 22 : 28`** | 보병 `50,806명` 달성으로 완성형 비율 적용 |
| **필드토벌** | **전망대 보스 · 체사레 · 괴수** | 헬가 · 제이벨 · 퀸 *(괴수는 다이애나)* | **`50 : 22 : 28`** | 1군 표준 밸런스 비율 |
| **전장공격** | **성검 쟁탈 · 사라진 유적 · 성소 (공격)** | 헬가 · 제이벨 · 퀸 | **`50 : 22 : 28`** | 1군 주력 공격 표준 비율 |
| **거점수비** | **성검 · 성소 · 왕성 · 도시 (주둔 방어)** | 헬가 · 제이벨 · 퀸 | **`60 : 20 : 20`** | 거점 방어는 보병 `60%` 탱킹 우선 |
| **연맹방어** | **바이킹의 약탈 (연맹 공지 `내 성 0명` 2부대 전량 파견)** | • `1부대`: **`[1번] 첸코`** + 하워드·다이애나<br>• `2부대`: **`[1번] 연우`** + 스미스·고든 | **보·기·궁 각 `50%`씩**<br>*(부대당 `~70.2K`)* | 총병력(`140.4K`)을 2부대로 반반 나눠 **내 성 잔류 `0명`** 완성 (`TC 22~24` 빈 성 독식) |
| **연맹방어** | **바이킹의 약탈 (내 성 `방위소`)** | 헬가 · 제이벨 · 퀸 | **잔류 병사 `0명`** | 내 1군 방위소 버프만 지원군에 제공 (맞지원 없을 때만 본성 `50%` 잔류) |
| **연맹방어** | **바이킹의 약탈 (`10·20웨이브` 평원 본부)** | **`[1번] 하워드` + `2·3번 영웅 필수`** *(3영웅 채워 `92.4K` 정원 개방)* | **`53 : 47 : 0`**<br>*(보병 전량 + 나머지 기병 풀충전)* | 1영웅만 넣으면 정원(`48.5K`)에 막혀 기병이 `0명` 들어감 (**`T8 기병` 킬 효율 = 보병의 `2.53배`**) |
